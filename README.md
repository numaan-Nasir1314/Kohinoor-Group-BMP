# Kohinoor Group - Business Management Portal

A modern, responsive business management website built with HTML, CSS, JavaScript, and Bootstrap 5.

## Features

- **Premium Login Page**
  - Glassmorphism design with blue and gold gradient background
  - Form validation
  - Show/Hide password functionality
  - Remember Me checkbox
  - Smooth animations and transitions
  - Loading animation during login

- **Modern Dashboard**
  - Responsive navigation bar with company branding
  - Four business cards in a responsive grid
  - Hover animations and interactive cards
  - Logout functionality

## Customization

To customize the website:

1. **Change Colors:** Edit the CSS variables in `style.css` under `:root`
2. **Update Credentials:** Modify `DEMO_CREDENTIALS` in `script.js`
3. **Add Business Cards:** Add new card HTML in `dashboard.html` and corresponding CSS in `style.css`
4. **Modify Animations:** Edit keyframe animations in `style.css`
